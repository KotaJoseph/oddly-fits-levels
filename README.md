# Oddly Fits level packs

Puzzle boards that the Oddly Fits game downloads each week. This folder holds data only: board shapes, arrow paths and difficulty ratings. The game checks every file against `manifest.json` (size and SHA-256) and its own rules before using it.

Published from the game project with `Tools/LevelLab/publish_pages.py`. Don't edit files here by hand, and never remove a pack that has been released.
